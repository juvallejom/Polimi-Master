## 1.1 Running time

The running time depends on the input: an already sorted sequence is easier to sort. Parameterize the running time by the size of the input, since short sequences are easier to sort than long ones.

Generally, we seek upper bounds on the running time, because everybody 
likes a guarantee.

## 1.2 Kinds of Analyses

1. Worst-case: (usually): T(n) = maximum time of algorithm on any input of size n
2. Average-case: (sometimes): T(n) = expected time of algorithm over all inputs of size n. Need assumption of statistical distribution of inputs
3. Best-case: (not-so-useful): T(n) = minimum time of algorithm on any input of size n. Cheat with a slow algorithm that works fast on some inpu
